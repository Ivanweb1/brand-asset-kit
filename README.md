# Brand Asset Kit — «Сначала процесс. Потом технология»

Библиотека фирменных элементов для видео, соцсетей, презентаций и сайта.
Палитра: Graphite `#111315` · Off White `#F5F4F0` · Electric Blue `#1769FF`. Шрифт: Manrope — крупные заголовки Medium, дескриптор SemiBold капсом без разрядки (как на утверждённых постерах).

**Быстрый старт**
1. Установите шрифты из `00_BRAND_GUIDE/fonts/` (нужны для SVG с живым текстом).
2. Откройте `10_PREVIEWS/catalog.html` — все элементы с поиском и переключателем фона.
3. Правила использования: `00_BRAND_GUIDE/brand-guide.pdf` (17 страниц).

## Фирменные приёмы

1. **Слово на синей плашке** — одно ключевое слово в заголовке (`label-highlight`, все шаблоны постов).
2. **Тумблер «ручной → авто»** — метафора «Выключаем ручной режим» (`label-toggle-switch`, `overlay-reels-toggle-switch`, карусель «До/После»).
3. **Гигантский модуль** — модули знака в масштабе кадра, уходящие за край (`bg-giant-modules-*`, обложка Reels).
4. **Зачёркивание** — «ручной режим» перечёркнут синей полосой (`label-strike`, `poster-manual-off`).
5. **Ленточные титры** для видео — каждая строка на своей плашке, ключевая синяя (`label-headline-bars`, `overlay-reels-title-*`).

## Как называются файлы

- `-on-light` / `-light-bg` — для светлого фона (графитовые элементы).
- `-on-dark` / `-dark-bg` — для тёмного фона (светлые элементы).
- `-accent` — с синим акцентным модулем. `-any-bg` — элемент только из синего, подходит к любому фону.
- `-empty` — пустая плашка: текст добавляете сами в монтажке.
- `-tile-dark` / `-tile-light` — иконка в квадратной плитке.
- Число в конце логотипа — ширина PNG в пикселях: `logo-mark-primary-1024.png`.

## Где что использовать

**Видео (CapCut, Premiere, DaVinci)**
- Оверлеи `06_VIDEO_OVERLAYS/PNG` — кладите на дорожку над видео 1:1, они уже размером 1080×1920 и стоят в безопасной зоне.
- Сначала включите `guide-safe-zones-1080x1920.png` как временный слой, чтобы проверить, что ваши титры не уходят под интерфейс Reels/Shorts.
- Плашки `04_LABELS/PNG/1x` — в масштабе кадра 1080, ставятся без масштабирования. `2x` — для 4K или если нужно увеличить.
- Пустые плашки `*-empty` — подложка; текст набирайте в редакторе шрифтом Manrope.
- Водяной знак — `01_LOGO/PNG/watermark-mark-white-70-256.png`, левый верхний угол (72 / 260 px).
- Лоадер: `09_EXTRA_ELEMENTS/PNG/loader-sequence-*` — импорт как последовательность изображений; GIF — для быстрых превью.
- Финал ролика — `overlay-reels-cta-end-screen.png` (непрозрачный экран).

**Посты и сторис**
- Редактируйте SVG из `08_SOCIAL_TEMPLATES/SVG` в Figma (Import → SVG: текст останется текстом) или в Illustrator/Inkscape.
- В обложке кейса есть группа `photo-slot` — замените её скриншотом или фото.
- Фоны из `07_BACKGROUNDS` подходят под свои макеты в Canva/Figma.

**Сайт и презентации**
- `00_BRAND_GUIDE/design-tokens.css` — CSS-переменные цветов и радиусов.
- Фавиконы: `09_EXTRA_ELEMENTS/PNG/favicon/` (ico, 16–512 px) и `favicon.svg`.
- Иконки берите в SVG: они на сетке 48 с обводкой 3 и масштабируются без потерь.

**Аватарки**: загружайте `logo-avatar-upload-dark-1024.png` — площадка сама обрежет квадрат в круг.

## Логотип

Геометрия знака взята из присланного оригинала `logo-mark.original.svg` без изменений: пути копируются программно, перерисовки нет. Менялись только цвета по правилам утверждённых вариантов. На синей подложке используется одноцветный светлый знак, чтобы синий модуль не терялся.
Текст в логотипах и локапах переведён в кривые.

## Пересборка из токенов

Все файлы генерируются кодом из `_source/`. Поменяйте цвет, радиус или безопасные зоны в `_source/tokens.json` и выполните:

```bash
cd _source
python build.py
```

Нужны Python 3.11+, `playwright` (Chromium), `fonttools`, `uharfbuzz`, `Pillow`. Флаги: `--no-png` — только SVG, `--no-zip` — без архива.

Структура генератора: `kit.py` — ядро (логотип, текст, кривые), `build_*.py` — секции, `render.py` — PNG через Chromium, `qa.py` — проверки, `catalog.py` — превью и руководство.

## Контроль качества (автоматически при каждой сборке)

- Все SVG валидны, есть `viewBox`, внутри нет растровых картинок.
- Все цвета в SVG — только из палитры и производных оттенков из токенов.
- Все символы текста есть в Manrope (кириллица, «—», «−», «×»).
- PNG элементов прозрачные, PNG фонов и шаблонов непрозрачные, размеры совпадают с заявленными.
- Геометрия не выходит за `viewBox` (проверка в Chromium).
- Одинаковые PNG под разными именами отсутствуют.

Отчёт: `_source/qa-report.json`.
