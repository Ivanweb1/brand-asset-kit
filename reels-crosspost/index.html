Reels Crosspost

Личный инструмент Ивана Панькина · Personal tool by Ivan Pankin

Reels Crosspost публикует мои собственные вертикальные видео сразу на нескольких площадках: в Telegram-канале, VK Клипах, YouTube Shorts и Instagram Reels. Я отправляю ролик своему Telegram-боту, проверяю подписи и нажимаю «Опубликовать» — дальше сервис сам загружает видео на мои аккаунты.

Сервис не публичный: им пользуется только владелец, и он работает только с аккаунтами владельца.

YouTube

Uses YouTube API Services

Для YouTube Shorts используется YouTube Data API (YouTube API Services): видео загружается на мой канал через videos.insert, после этого статус обработки проверяется через videos.list.

This app uses YouTube API Services. See the YouTube Terms of Service, the Google Privacy Policy and our Privacy Policy.

Reels Crosspost is a personal tool that publishes the owner's own short vertical videos to the owner's Telegram channel, VK, YouTube Shorts and Instagram Reels. For YouTube it uses YouTube API Services (YouTube Data API v3) to upload videos to the owner's channel and check their processing status. It is not offered to other users.
