# Ролик «Сотрудник собирает отчёт» (сценарий R003)

- Исходник: `_1080p.1.mp4` — 22,4 с, 1080×1920, 25 к/с, SDR, аватар HeyGen.
- Где лежит: релиз `raw-2026-10-28` — https://github.com/Ivanweb1/brand-asset-kit/releases/tag/raw-2026-10-28
- Скачать:
  ```bash
  curl -L -o raw.mp4 "https://github.com/Ivanweb1/brand-asset-kit/releases/download/raw-2026-10-28/_1080p.1.mp4"
  ```
- Пересобрать:
  ```bash
  cd _tools/reels
  python3 prepare.py raw.mp4 --start 0 --sharpen 0.5 --work work
  cp example-r003-report/edit.json work/edit.json
  REEL_COVER=example-r003-report/cover.jpg REEL_WORK=work python3 r003_report.py light   # -> work/out/reel_r003_report_light.mp4
  ```
- Готовый ролик: `final.mp4` — 19,2 с, 1080×1920, 30 к/с, около 9 Мбит/с, −16 LUFS. Первый кадр — обложка.

## Монтаж
- Аватар говорит без оговорок: вырезаны только паузы между фразами (10 кусков).
- Поправлены тайминги слов, которые распознавание поставило в одну точку («Из одной», «И за»).
- В субтитрах так, как сказано: «Напишите в директ слово «АУДИТ». Я разберу, …».

## Графика
- Хук, полный кадр: «Три часа каждую неделю» → синяя «Копирует цифры для отчёта» (на «копирует»).
- «Из одной таблицы в другую»: панель, «ДО · ВРУЧНУЮ» (Цифры, Из таблицы, В другую) и пустая заготовка; на «компания» в ней «Компания платит зарплату».
- «Хотя отчёт может собираться сам»: «ОТЧЁТ МОЖЕТ — Собираться сам», тумблер ручной → авто на «сам».
- «Система переносит данные…»: «ПОСЛЕ · СИСТЕМА» (Данные, Готовый отчёт, Проверить) — строки на словах.
- Призыв, крупный план: «Напишите в директ» + «„АУДИТ“».

## Обложка
**Выбрана:** `cover.jpg` — «Отчёт / **составляется сам**». Кадр 8,9 с исходника (глаза открыты, рот закрыт, лёгкая улыбка), приближение 1,4.
Остальные варианты: `cover-a.jpg` «Три часа каждую неделю / сотрудник просто / **копирует цифры**», `cover-b.jpg` «Отчёт / **может составляться сам**», `cover-c.jpg` «Отчёт / **готовится сам**», `cover-d.jpg` «Отчёт / **делается сам**».
