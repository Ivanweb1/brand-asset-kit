# Ролик «ИИ-агент отвечает на заявки» — версия 1080p без водяного знака

Тот же сценарий, что в `example-ai-agent/`, но исходник из HeyGen выгружен заново: 1080p и без водяного знака.

- Исходник: `_1080p.mp4` — 29,8 с, 1080×1920, 25 к/с, SDR, аватар HeyGen.
- Где лежит: релиз `avatar-1080` — https://github.com/Ivanweb1/brand-asset-kit/releases/tag/avatar-1080
- Скачать:
  ```bash
  curl -L -o raw.mp4 "https://github.com/Ivanweb1/brand-asset-kit/releases/download/avatar-1080/_1080p.mp4"
  ```
- Пересобрать:
  ```bash
  cd _tools/reels
  python3 prepare.py raw.mp4 --start 0 --sharpen 0.5 --work work
  cp example-ai-agent-1080/edit.json work/edit.json
  REEL_COVER=example-ai-agent-1080/cover.jpg REEL_WORK=work python3 ai_agent_1080.py light   # -> work/out/reel_ai_agent_1080_light.mp4
  ```
- Первый кадр ролика — обложка `cover.jpg` (переменная `REEL_COVER`): Instagram по умолчанию берёт обложку с него.
- Готовый ролик: `final.mp4` — 24,6 с, 1080×1920, 30 к/с, около 9 Мбит/с, −16 LUFS.

## Отличия от первой версии
- Текст новой записи чуть другой: нет фразы «И самое обидное». Панель после хука теперь «ДЕЛО МОЖЕТ БЫТЬ — Вообще / не в рекламе», остальные сцены и тексты те же.
- Куски речи: 12 вместо 14, поэтому в `ai_agent_1080.py` сдвинуты индексы сцен (`S[7]` вместо `S[8]`, `S[11]` вместо `S[12]`) и слов (`E.wt`).
- Поправлены тайминги слов, которые распознавание поставило в одну точку («Вы заплатили», «а клиент», «И дело», «но менеджер», «и клиент», «а потом»).
- «и агент» в расшифровке → «ИИ-агент», «менеджера» → «менеджеру».

## Почему стало резче
Первая версия собиралась из исходника 720p, растянутого в 1,5 раза и ещё приближенного в монтаже, поэтому была мягкой. Сейчас:
- исходник 1080p;
- `prepare.py` масштабирует через Lanczos (было bicubic) и может слегка поднять резкость: `--sharpen 0.5` для 1080p, `0.7` для 720p; для 4K с iPhone не нужен;
- камера в `reel.py` — Lanczos вместо bicubic;
- итоговое сжатие в `story.py` — CRF 14 (было 17), чтобы после пересжатия в Instagram оставалось больше деталей.
По замеру деталей кадр примерно на 65% чётче, чем в первой версии.

## Обложка
**Выбрана:** `cover.jpg` (= `cover-1.jpg`, «Платите за заявки, / а клиенты уходят / к конкурентам?»).

Три варианта хука, кадр 0,8 с исходника (открытые глаза, улыбка, взгляд в камеру), приближение 1,4:
- `cover-1.jpg` — «Платите за заявки, / а клиенты уходят / **к конкурентам?**»
- `cover-2.jpg` — «Клиент оставил заявку / **и ушёл к конкуренту**»
- `cover-3.jpg` — «Теряете клиентов / **не из-за рекламы**»

Заголовок и лицо целиком в центральном квадрате 1080×1080 (y 420…1500) — так Instagram показывает ролик в ленте; квадрат входит и в обрезки 4:5 и 3:4. Собрать заново или с другим текстом:
```bash
python3 cover.py raw.mp4 --t 0.8 --line "Платите за заявки," --line "а клиенты уходят" --line "*к конкурентам?" --out cover.jpg
```
