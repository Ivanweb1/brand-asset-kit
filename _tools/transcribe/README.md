# Транскрибация видео (русский, офлайн)

Скрипт распознаёт речь и сохраняет текст с таймкодами каждого слова — для субтитров, монтажа по паузам и подстройки графики под слова.

```bash
python3 _tools/transcribe/transcribe.py путь/к/видео.mov
```

Рядом с видео появятся:
- `*.txt` — текст по фразам с таймкодами;
- `*.srt` — субтитры;
- `*.words.json` — слова с временем начала, фразы и паузы (для монтажа).

Модель — открытая `sherpa-onnx-zipformer-ru` (k2-fsa). Она скачивается из релизов GitHub (≈300 МБ, один раз в `~/.cache/brand-asr`), поэтому работает и там, где закрыт huggingface.co. Зависимости `sherpa-onnx` и `soundfile` скрипт ставит сам.

Текст получается без заглавных букв и знаков препинания — для субтитров их нужно расставить вручную.
