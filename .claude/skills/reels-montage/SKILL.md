# Монтаж Reels по утверждённому формату

Перед работой прочитай `_tools/reels/RULES.md` — это обязательные правила (утверждены пользователем 25.10.2026). Эталон: `_tools/reels/example/final.mp4`.

## Порядок
1. **Получить видео.** Большие файлы пользователь загружает в релиз этого репозитория (Releases → новый тег → Attach binaries). Скачать: `curl -L -o raw.MOV https://github.com/Ivanweb1/brand-asset-kit/releases/download/<тег>/<файл>`.
2. **Подготовить:** `python3 _tools/reels/prepare.py raw.MOV --start <с> --end <по> --work work`. Получатся src.mp4, звук, расшифровка (`_tools/transcribe`, модель с GitHub, huggingface не нужен) и черновик `work/edit.json`.
3. **Монтаж-лист:** открой расшифровку и `edit.json`. Оставь только чистую речь: убери паузы, «а», «э», «ну», оговорки, повторы, паузы на подумать. В `words` расставь заглавные буквы и пунктуацию. Проверь: `REEL_WORK=work python3 _tools/reels/edit.py`.
4. **Сценарий графики:** скопируй `before_after.py` и привяжи сцены к словам нового текста через `E.wt(индекс)`. Структуру формата (имя → тема с тумблером → вопрос → тезис в двух карточках → разбор «ДО · вручную / ПОСЛЕ · система»), сетку, тайминги и стиль не меняй. Новые визуализации делай из элементов кита и только по смыслу сказанного.
5. **Проверка:** `peek.py ... --zones` на 6–8 ключевых моментах. Текст не заходит в зоны интерфейса Reels, всё выровнено по центру или симметрично, лицо не перекрыто. Сравни с эталоном.
6. **Рендер** и отправка пользователю. Коротко перечисли, что вырезано из речи и какие визуализации стоят на каких словах.

## Нельзя
- Перерисовывать логотип или брать интро из `11_MOTION` (знак там собран неправильно) — только `logo()` из оригинального SVG.
- Ставить логотип в угол на весь ролик, начинать ролик с интро.
- Округлять зум до пикселей (кадр трясётся), класть текст под правую колонку кнопок или ниже 1600 px.
- Выдумывать цифры и факты для визуализации, которых нет в речи.
